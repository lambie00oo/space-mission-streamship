# SPACE ODYSSEY — Streamlit 궤도 설계 게임

## 실행 방법

1. VS Code에서 이 폴더를 엽니다.
2. 터미널에서 가상환경을 만들고 활성화합니다.
   - Windows: `py -m venv .venv`
   - PowerShell: `.\.venv\Scripts\Activate.ps1`
3. 필요한 패키지를 설치합니다: `pip install -r requirements.txt`
4. 실행합니다: `streamlit run app.py`

## 게임 진행

도입부 → MISSION1 교육 → MISSION2 궤도 계산 → MISSION3 전이 시간·도착 위치 계산 순서로 진행합니다.

- MISSION1은 타원, 이심률, 케플러 법칙, 호만 전이 궤도 교육 내용을 제공합니다.
- MISSION2: 선택한 행성의 평균 태양 거리와 공전 주기를 확인하고, 장반경·이심률·초점 거리를 순서대로 계산한 뒤 전이 타원을 확인합니다.
- MISSION3: 365.25일/년을 기준으로 전이 시간을 구하고, 공전 각속도·행성 이동 각도·위상각을 도 단위로 계산해 궤도에 표시합니다.
- 행성의 평균 태양 거리와 공전 주기는 `data/planets.py`에 한 번만 정의하며, 행성을 바꾸면 두 미션의 입력과 진행 상태가 초기화됩니다.
- 정답을 맞혀야 다음 계산 단계가 열립니다. 오답에는 단계별 힌트가 표시됩니다.
- 행성 궤도는 원형으로 근사한 교육용 모델입니다.
- MISSION1~MISSION3 화면 오른쪽의 공학용 계산기에서 괄호, 사칙연산, 거듭제곱, 제곱근, π와 과학적 표기법을 사용할 수 있습니다. 계산 기록은 미션을 이동해도 세션 동안 유지됩니다.
- 계산기는 허용된 산술 수식만 파싱하며, Python 코드를 실행하지 않습니다.

화면에서 기존 `images/` 폴더의 파일을 직접 참조합니다. 이미지를 별도로 복사하지 않습니다.

우주비행사 프로필, MISSION4 및 마우스로 타원을 조절하는 기능은 현재 구현 범위에 포함하지 않습니다.
